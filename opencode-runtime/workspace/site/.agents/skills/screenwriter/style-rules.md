# 剧本写作规则

## 总规则

1. **动作动词。拒绝描写。**
   摄影机只能拍下看得见、听得见的东西。不许有「他觉得」「他明白」「他脑海中闪过」「气氛紧张」。只有动词（打、走、抓、看、低语……）。

2. **极简即天赋。** 能用两个字说清的，就用两个字。多一行 = 多一分钟银幕时间。

3. **只改用户要求改的。** 定点修改，不「优化」旁边的台词。

4. **好莱坞格式。**
   - 场景标题（Slug-line）：全大写、加粗、左对齐
   - 动作描述（Action）：左对齐、现在时、仅限动作动词
   - 角色名（Character cue）：全大写、缩进约 2.2 英寸（3168 DXA）
   - 括号提示（Parenthetical）：缩进约 1.6 英寸（2304 DXA）
   - 对白（Dialogue）：左缩进 1 英寸 + 右缩进 1.5 英寸（1440 / 2160 DXA）
   - 转场（Transition）：右对齐、全大写

5. **只给一个版本，不给五个。** 提交一场戏时给一个版本 + 一条理由。如果用户否决，问一个窄口径二选一问题，然后给出下一个版本。

6. **场景标题格式。** `内景/外景. 地点 — 时间`。时间通常用：黎明 / 白天 / 傍晚 / 夜晚。场景标题语言全程统一（要么全中文，要么全英文，项目启动时确定）。

## 反面示例 vs 正面示例

❌ 「灰色的晨曦将雪山之巅染成玫瑰色。古老的神庙矗立在深渊之上。」

✅ 「外景. 山脉 — 黎明。三个身影掠过雪脊。」

---

❌ 「主人公感到心碎，眼中充满了悲伤。」

✅ 「主人公望向山峦。」（他感受到什么，交给演员去演。）

---

❌ 「女老师带着神秘的微笑，用一种饱含百年智慧的声音说：」

✅ 「女老师：「你自己知道。」」

---

❌ 「一场惨烈的战斗正在进行，主人公为生存而战，展现出惊人的决心。」

✅ 「主人公挥拳。敌人倒下。主人公转身。第二个敌人已在身后。」

---

## 人物语言指纹

每个主要角色都必须有**可辨识的声音**。遮住名字读台词——应该能说出是谁在说话。

声音维度：
- **台词长度** — 短 / 长
- **语域** — 书面 / 口语 / 俚语
- **口头禅/俚语** — 有 / 无，具体是什么
- **语言中的自我评价** — 是否爱辩解 / 是否认错
- **沉默** — 谁比别人话少？沉默本身就是特征
- **语言模式** — 哪些话反复说

一个好用的技巧：给每个角色一个**对同一人的独特称呼**。有人叫名字，有人叫外号，有人从不直接称呼对方。

## 节奏与速率

- **打斗 / 追逐戏** — 短句动词，一行一个动作。剪切节奏。

  ```
  主人公挥拳。
  敌人倒下。
  主人公拾起剑。
  ```

- **对白戏** — 台词要短，停顿用动作表示（「主人公沉默」，而不是「主人公不知道说什么所以沉默了」）。

- **气氛戏** — 同样通过动作呈现，不写状态描述。

  ❌ 「气氛变得越来越紧张。」
  ✅ 「灯灭了。只剩下呼吸声。」

---

## 必须避免

- **角色的内心独白。** 能通过动作展示的，就用动作展示。
- **超过一行的景物描写。** 一个镜头 = 一行。
- **情绪形容词**（「紧张的」「不祥的」「神秘的」）。情绪是观众的感受，不是编剧该写的。
- **通过对白直接向观众解释**（「你还记得吧，我们是近亲，我妈1992年被人害死了」）。这叫「信息倾倒」（info dump）——低级错误。
- **重复画面已有信息的台词。** 如果角色在哭——不需要他说「我很难过」。

---

## 应当坚持

- **物件即地雷。** 电影中每一次物件出现都必须推动情节。如果第一幕展示了一把枪——第三幕它必须开火（契诃夫法则）。如果展示了两次——第三次一定要用上。
- **台词的回响。** 同一句台词在不同语境下重复，就成了意义的地雷。电影开头的「我爱你」和杀人前的「我爱你」——不是同一句话。
- **沉默。** 观众期待台词的时刻，角色选择沉默——这是电影中最响亮的声音。
- **对称。** 第一场戏和最后一场戏应当形成呼应。通过物件、地点、台词或动作。
