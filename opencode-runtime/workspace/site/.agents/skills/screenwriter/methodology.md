# 剧作方法论

我们始终以三大经典为基石。

---

## 罗伯特·麦基 —《故事》

### 主控思想（Controlling Idea）

一句话形式：**「生活变得如何如何，是因为主人公做了什么什么，原因是什么什么。」** 这是整部电影的脊椎。每一场戏都必须为它服务。

如果你不能用一句话说清主控思想——这部电影没有脊梁。先有思想，后有场次。

### 场景价值（Scene Value / 价值转向）

任何一场戏里，**总有什么东西发生了变化**——从正到负，或从负到正。价值以一种状态入场，以另一种状态出场。

**没有价值转向的场景 = 不是场景。** 那只是一段描述。

动笔写一场戏之前，先回答：
- 入场时的价值是什么？（例如：信任。）
- 处于什么状态？（例如：团队信任领袖。）
- 出场时的价值是什么状态？（例如：团队开始怀疑领袖。）
- 是什么动作翻转了价值？

常见价值对：
- 掌控 ↔ 无助
- 信任 ↔ 背叛
- 爱 ↔ 执念
- 生 ↔ 死
- 自由 ↔ 囚禁
- 秩序 ↔ 混乱
- 伙伴 ↔ 工具
- 希望 ↔ 绝望
- 知 ↔ 无知

### 激励事件（Inciting Incident）

打破主人公生活平衡的事件。必须发生在影片**前四分之一**内（90分钟片长约在第22分钟前）。

没有这个事件，故事就不会启动。事件发生前和发生后，主人公的生活是两个完全不同的世界。

### 渐进式复杂（Progressive Complications）

每一个后续冲突都比前一个更强烈。主人公的预期与行动结果之间的鸿沟——不断扩大。

如果第三幕的冲突反而比第一幕弱——结构出了问题。

### 危机 → 高潮 → 结局（Crisis → Climax → Resolution）

- **危机（Crisis）**：主人公最后的两难。在两种不可兼得的价值之间做出选择。全片最难的一刻。
- **高潮（Climax）**：回应两难的行动。全片最具身体性、最有冲击力的一刻。
- **结局（Resolution）**：高潮之后新世界的短暂坐标。

### 正负摆锤

主人公不能一直赢也不能一直输。正负交替。每一次摆动振幅都在加大。

在坠落弧中，「正」是局部的（小胜利），「负」是系统性的（大损失）。
在上升弧中则相反。

### 展示，而非告知（Show, don't tell）

用动作和物件代替内心独白。画面中的一个物件，胜过十句台词。

验孕棒代替「她怀孕了」这句台词。
撕碎的信代替「他和她分手了」。
空椅子代替「他很孤独」。

## 约瑟夫·坎贝尔 —《千面英雄》

把坎贝尔**当作诊断工具，而非教条**。不是每个故事都是纯粹的英雄之旅。尤其当你写反英雄或悲剧时——那是镜像之旅（*katabasis*，有去无回，如俄耳甫斯寻欧律狄刻）。

### 12阶段

1. **日常世界** — 主人公处于平衡中。先让观众看到他拥有什么，才会懂他将失去什么。
2. **冒险召唤** — 迫使主人公走出舒适区的事件。
3. **拒斥召唤** — 主人公犹豫、恐惧。没有这个阶段，主人公就不是主人公，只是一个功能件。
4. **遇见导师** — 有人给予工具、技能或知识。导师也可能是假的——即阴影。
5. **跨越第一道阈值** — 主人公穿过两个世界的边界。
6. **考验、盟友、敌人** — 在新世界中立足。
7. **接近洞穴深处** — 为终极考验做准备。
8. **核心考验** — 与死亡或阴影正面遭遇。
9. **获得奖赏** — 主人公得到了他追寻的东西。
10. **归途** — 回到日常世界（对反英雄而言——可能再也回不去了）。
11. **复活** — 最后的考验。主人公死去又重生。
12. **带着灵药归来** — 主人公给世界带回了新的东西。

### 原型

- **英雄**：主动推动情节的人。
- **阴影**：反英雄，主人公黑暗面的镜像。
- **导师**：给予工具的人。
- **阈值守卫**：进入新世界的障碍。
- **信使**：宣告召唤的人。
- **变形者**：改变立场的人。
- **捣蛋鬼**：喜剧角色，打破规则。

在反英雄悲剧中，**导师往往就是阴影**。主人公到最后才明白，教他的人正是害他的人。

## 亚里士多德 —《诗学》

### Ἁμαρτία（哈马提亚）— 英雄的致命缺陷

不是道德意义上的「罪」，而是性格中的某种偏差，它触发了悲剧。好的主人公有一个弱点——在正常生活中它甚至是一种美德，但在极端情境下——它就是灾难。

「我爱得太深」——这就是浪漫悲剧中的哈马提亚。
「我对谁都信任」——在政治悲剧中。
「我无法原谅」——在家庭悲剧中。

哈马提亚必须**从第一场戏就可见**，并在**高潮处彻底爆发**。

### Περιπέτεια（突转 / 佩里佩特亚）— 行动转向其反面

本应导致 A 的行动，结果导致了非 A。

想要拯救，结果杀死了。
想要保护，结果摧毁了。
想要揭开真相，结果永远关上了那扇门。

一部好电影有 2-3 次突转，力度逐层递增。

### Ἀναγνώρισις（发现 / 阿纳格诺里西斯）— 认知翻转

主人公（或观众）突然明白了一直被隐藏的真相。

最好的发现——是**与突转同时发生**的。双重打击：主人公在得知真相的同一刻，他的行动也走向了自己的反面。

### Κάθαρσις（卡塔西斯 / 净化）— 通过恐惧与怜悯获得净化

结局应当在观众心中唤起一种混合的情感——对主人公的怜悯，与对自身的恐惧（「我也可能成为他」）。

### 行动的整一性

亚里士多德要求悲剧中的一切都指向同一个终点。每一个动作、每一件物品、每一句台词都必须为最终的落点服务。

**如果一场戏不为终点服务——它就是多余的。** 检验方法很简单：删掉这场戏，电影会变吗？如果不会——剪掉。

## 如何使用这套方法论

写每一场戏之前，先问自己：

1. 主控思想是什么？（来自麦基）
2. 这场戏入场价值是什么？出场价值是什么？
3. 对应坎贝尔的哪个阶段？（如果适用）
4. 这场戏如何服务于主人公的哈马提亚？
5. 这是一场突转戏，还是铺垫戏？

如果答不上来——这场戏要么不需要写，要么需要重新构思。
