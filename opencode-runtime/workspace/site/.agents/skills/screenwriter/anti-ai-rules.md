# 去AI味规则（15条戒律）

以下是机器写作剧本的典型指纹。每一条都是**必须消除的缺陷**，不是可选建议——写完一场戏后对照自查，命中任何一条都要修改后再交付。

> 注：动作动词原则、对白自然度、人物声音区分度由 `style-rules.md` 负责，本文件聚焦于「AI味」特有的语言与结构痕迹。

---

## 语言修辞层（第1-6条）

### 1. 比喻堆砌 = 注水

「仿佛 / 似乎 / 宛如 / 犹如 / 不是……而是……」这类词每段**不超过1个**。堆叠的比喻会互相抵消——一个精准的暗喻或通感，胜过三个明喻。

❌ 「月光如水般倾泻，仿佛银色的丝绸，又像是一层薄薄的霜。」

✅ 「月光落在地上，发白。」

### 2. 句式节奏单一 = 机器味

全是 15-25 字的句子，长短整齐划一——读起来像机器生成的。人写的句子长短交替，有长句也有短句，甚至有一两个字的句子。

**自查方法**：随便选一段，数句子字数。如果连续5句都在 10-25 字区间——重写。

### 3. AI陈词滥调 = 立刻删除

以下词语和句式一出现就是AI味警报，**一律删除或替换为具体动作**：

- 形容词：无与伦比、令人叹为观止、独一无二、意义非凡
- 副词：深深地、缓缓地、微微地、静静地、默默地
- 动词：展现出、彰显出、体现出、勾勒出、描绘出
- 句式：「在这个XX的时代」「随着XX的发展」「XX的背后是XX」

❌ 「他缓缓地转过身，眼中展现出深深的悲伤。」

✅ 「他转身。没说话。」

### 4. 空洞的程度副词 = 稀释力量

「非常 / 极其 / 十分 / 特别 / 显然 / 当然 / 格外」——这些词不增加信息，反而削弱表达。删掉它们，或者用具体描写替代。

❌ 「她非常生气。」

✅ 「她把杯子往桌上一顿。水溅出来。」

### 5. 「总-分-总」三段式 = 论文味

AI写东西喜欢「观点→展开→总结」的三段式结构，像写议论文。剧本的动作描述应当是流动的、跳跃的，像摄影机的视线一样移动，而不是有条有理地论述。

❌ 「这间房间很破旧。墙上的墙纸已经剥落，角落里堆满了杂物，窗户也碎了一块。总而言之，这里很久没有人住过了。」

✅ 「墙纸卷着边。墙角堆着旧纸箱。窗玻璃缺了一块，风往里灌。」

### 6. 形容词堆叠 = 装饰过度

连续两个以上形容词修饰同一个名词——AI最爱这么干。人写的剧本通常一个名词配一个修饰，甚至不加修饰，让上下文自己说话。

❌ 「昏暗、潮湿、散发着霉味的地下室里，一个瘦弱、憔悴、眼神空洞的男人蜷缩着。」

✅ 「地下室里，一个男人蜷缩在角落。他咳嗽。」

## 结构层（第7-12条）

### 7. 段落长度均匀 = 机器指纹

AI写的段落总是差不多长，像用尺子量过一样。人写的剧本有长段有短段，甚至有单句成段、空行留白。

**自查方法**：滚动页面看视觉形状——如果像一块整齐的砖——有问题。

### 8. 完美信息传递 = 教科书味

AI给出的信息总是刚刚好、不多不少、逻辑严丝合缝——像教科书。真实的剧本有冗余、有跳跃、有观众自己要拼起来的碎片。环境描写也不是清单式盘点——选一个焦点，让它映照剧情。

❌ 「厨房不大，里面有一张桌子，四把椅子，一个冰箱，一个灶台，墙上挂着一口钟。」

✅ 「桌上放着半碗冷饭。钟停了。」

### 9. 情感模板重复 = 单薄

同一章/同一场戏里，同一种生理反应重复出现（比如三次「心一紧」、两次「倒吸一口凉气」）——AI味。换着来：胃里发凉、忘了呼吸、指尖发麻、喉咙发紧、耳朵嗡的一声、后颈发凉。

每个角色的情绪反应也应当不同——有人紧张时话多，有人沉默，有人手抖，有人笑。

### 10. 每场都是「平静→冲突→高潮→钩子」 = 模板味

如果每一场戏都严格按照同一个节奏走——结构感太强就假了。有的戏可以只有氛围，有的戏可以是纯信息，有的戏可以戛然而止。节奏本身就应该有起伏。

### 11. 场景碎片化 = 硬伤

AI写剧本喜欢频繁切分，每两三百字就来一个场景切换或分割符。如果相邻段落发生在同一时间同一地点，用任何方式切开（分割线、空行、「话说」「且说」）都是错误的——用软过渡缝合。

合法的分割只有一种：**真的发生了时间/空间跳跃**，且两边都有足够的戏份支撑。一整幕戏里最多1-2次。

### 12. 角色从不误判 = 上帝视角

一个永远不会看错、不会漏看、不会有偏见的角色——或者全知全能的心理描写（「他内心深处其实渴望着……」）——读起来像作者的传声筒。

人会误判、会偏见、会想错。第一人称（如果用）应该是不可靠的。每个角色的内心节奏也不同——理性的人一步步想，冲动的人碎片式想。

## 内部思维层（第13-15条）

### 13. 感觉先于思考 = 生理真实

身体反应在前，思考在后——这样写才有身体感。永远深刻的内心独白像议论文；「等等她刚才说什么来着？我今天还没吃早饭」才像真实的念头。

❌ 「他意识到自己陷入了一个巨大的阴谋，心中充满了愤怒和恐惧。」

✅ 「他的手先抖了。然后才反应过来——那封信是真的。」

### 14. 对白不是辩论赛 = 口语真实

AI写对白喜欢每句都工整对仗、逻辑完美、金句频出。真实的人说话会：
- 说半截话
- 重复
- 跑题
- 说错了改口
- 用语气词（「嗯」「啊」「那个」「就是」——但别滥用）
- 答非所问
- 同时开口又同时停下

当然，剧本要精炼——但精炼不等于工整。留一点「毛边」，人物才像活人。

### 15. 信息不一次性给完 = 悬念真实

AI喜欢把背景信息一次性倾倒完毕（info dump），然后进入剧情。真实的剧本是**边行动边给信息**——观众到第三幕才拼凑出全貌，这才是观影的乐趣。

每一场戏只给观众刚好够理解当下的信息。剩下的——留着。

## 实用技巧

### 语义熵注入
在读者预期的位置，放一个「不太可能出现」的选择。比如紧张时刻突然出现一个荒诞细节。

### 节奏破局
在流畅的叙述中插入一句极短、极硬的话。「他跑过雨后湿滑的巷子，鞋底啪嗒踩水，路灯把影子拉长。**他很冷。** 他继续跑。」

### 通感
跨感官描写。「她的笑是淡粉色的」「他的目光是凉的」——但整部戏里用一两次就够，多了就成了炫技。

### 留白
不要把话说满。一句台词说完后留一个动作节拍，让观众自己填。

## 交付前自查清单

写完一场戏后，快速过一遍：

- [ ] 有没有「缓缓地/深深地/微微地」这类副词？
- [ ] 有没有「展现出/彰显出/体现出」这类动词？
- [ ] 比喻有没有超过每段1个？
- [ ] 句子长短是不是太整齐了？
- [ ] 段落长度是不是太均匀了？
- [ ] 情绪反应有没有重复用同一个？
- [ ] 角色是不是永远正确、永远判断准确？
- [ ] 对白是不是太工整、太像写出来的而不是说出来的？
- [ ] 信息是不是一次性给太多了？
- [ ] 同一场景内有没有不必要的切分？

命中3条以上——回去重写。
