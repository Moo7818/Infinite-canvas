# 专业编剧技能 — 快速上手

为编剧打造的专业级技能工具。不绑定具体故事，开箱即用。

---

## 包含内容

- **`SKILL.md`** — 技能主入口（AI 读取的第一个文件）。
- **`methodology.md`** — 麦基 + 坎贝尔 + 亚里士多德三大方法论。
- **`style-rules.md`** — 好莱坞格式剧本写作规则。
- **`anti-ai-rules.md`** — 去AI味规则（15条戒律，消除机器写作痕迹）。
- **`workflow.md`** — 协作工作流。
- **`timing-and-cutting.md`** — 银幕时长测算与篇幅裁剪。
- **`templates/`** — 梗概、人物小传、世界观、分场大纲空白模板。
- **`tools/`** — .docx 生成工具（剧本、双语剧本、分场大纲）。

---

## 开始使用

### 第一步：引入技能

在对话中说：「加载 screenwriter 技能，我们开始写剧本。」

AI 会自动阅读 SKILL.md、方法论、写作规则、去AI味规则和工作流。

### 第二步：带来你的素材

任选一种方式开始：

**A. 你已经有梗概 / 分场大纲 / 场次草稿。**
直接发文件——AI 会读完，然后问你从哪里开始。

**B. 你只有一个想法。**
用一两段话说出来。AI 会先问几个问题，帮你把梗概捋出来，再做分场大纲，最后写场次。

**C. 你只有一个标题和类型。**
用 `templates/synopsis.template.md` 和 `templates/characters.template.md` 填空。然后迭代推进。

### 第三步：逐场迭代

标准循环：
1. 你根据分场大纲要点某一场。
2. AI 给出**一个版本 + 一条理由**。
3. 你提修改意见。
4. AI 定点修改。
5. 场次定稿后——用 `tools/build_screenplay.js` 导出 .docx。

---

## 导出工具

### 好莱坞格式剧本
```bash
# 复制 build_screenplay.js 到你的工作目录，重命名
# 编辑文件，在 screenplay 数组里填场次
node build_screenplay.js
# 生成 screenplay.docx
```

### 双语剧本（对白+翻译）
```bash
# 用 dialB("主语言", "翻译") 写每句对白
node build_bilingual.js
# 生成 screenplay-bilingual.docx
```

### 分场大纲
```bash
# 用 scene("标题", "描述", "[可选]审计标签") 写每场
node build_treatment.js
# 生成 treatment.docx
```

## 常见需求速查

| 需求 | AI 会做什么 |
|---|---|
| 「写第5场」 | 读分场大纲 → 写一个版本 + 理由 |
| 「这个不行」 | 问一个窄口径二选一问题 → 下一个版本 |
| 「做双语版」 | 用 `tools/build_bilingual.js` 生成 |
| 「做因果链审计」 | 逐场过，用 ⚠ 标签标出问题 |
| 「大概有多长？」 | 按场次类型精确计算时长 |
| 「控制在X分钟以内」 | 给出具体裁剪方案，带数字 |
| 「让Y角色的声音和X区分开」 | 对比台词，提出修改方案 |
| 「去AI味审查」 | 按15条戒律逐条检查并修改 |

---

## AI 不会做的三件事

1. **不给5个版本** —— 只给1个 + 理由。
2. **不「顺便优化」旁边的台词** —— 只改你要求改的。
3. **不写情绪描写** —— 只写动作动词。

如果 AI 违反了——直接说「一个版本，不要五个」或「只改这句台词」。

## 自定义技能

如果你长期写同一类型的剧本——可以 fork 这个技能，添加：

- **`reference-films.md`** — 参考电影列表 + 场次分析。
- **`my-style.md`** — 你的个人风格偏好（比如「不用闪回」「结尾一定要静」）。
- **`recurring-tropes.md`** — 你常用的叙事手法。

让技能变成你的，而不是通用的。
