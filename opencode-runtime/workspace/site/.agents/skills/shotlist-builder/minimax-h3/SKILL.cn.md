## 🛍️ 商业广告与产品营销

> 为产品或品牌制作有说服力的宣传内容。

### 极简产品广告生成器
**一句话：** 基于产品图片，快速生成极简风格的电商广告短片。

- 适合：电商推广、新品发布、小品牌上新、食品/潮玩/数码配件
- 输入：产品图 + 广告需求
- 输出：有节奏、有质感的产品广告成片
- 不适合：KOC 口播广告、复杂录屏演示

[→ 查看完整技能文档](minimalist-product-ad-generator/SKILL.cn.md)

---

### 品牌宣传短片生成器
**一句话：** 基于品牌素材与推广目标，完成从策划到成片的品牌宣传视频。

- 适合：产品发布、官网展示、社交媒体推广
- 输入：LOGO / 产品图 / 界面截图 / 官网链接等可核验素材
- 输出：突出产品功能与使用场景的宣传短片
- 不适合：无授权素材时仿造品牌标识、虚构产品功能

[→ 查看完整技能文档](brand-promo-video-generator/SKILL.cn.md)

## 🎬 动画与叙事创作

> 用动画讲述一个完整的故事。

### 3D 动画短片生成器
**一句话：** 从一句故事创意开始，制作角色一致、场景连续的完整 3D 动画短片。

- 适合：剧情动画、生日纪念、品牌故事、社媒短片
- 输入：故事创意 / 基础剧情 + 时长 / 比例 / 风格确认
- 输出：角色一致、节奏完整的 3D 动画成片
- 流程：简报 → 大纲 → 角色/场景卡 → 镜头表 → 分镜 → 逐镜生成 → 拼接 → BGM → 复审
- 不适合：单张图片、简单修图、真人写实、仅一个独立镜头

[→ 查看完整技能文档](3d-animation-short-generator/SKILL.cn.md)

## 📚 教育科普与知识讲解

> 用独特的视觉语言把知识讲清楚、讲有趣。

### 纸艺定格科普视频生成器
**一句话：** 用手工纸艺视觉（纸雕、剪纸、立体书）讲解科学或知识主题。

- 适合：科学科普、教育内容、泛知识讲解
- 输入：主题 / 核心知识点 / 原始材料
- 输出：纸艺定格科普视频创作包（或静帧 / 分镜 / 提示词等单项资产）
- 特色：分层纸雕布景、纸偶角色、手工质感
- 不适合：普通二维卡通、线稿涂鸦、无纸艺质感的标准科普

[→ 查看完整技能文档](papercraft-stop-motion-explainer/SKILL.cn.md)

---

### 纸拼贴讲解动画生成器
**一句话：** 用触感纸拼贴风格，把文案、观点或抽象概念做成讲解动画。

- 适合：口播文案、知识讲解、观点表达、社交 B-roll
- 输入：短文案 / 故事节点 / 核心概念
- 输出：纸拼贴动画素材或完整讲解视频
- 特色：半调拼贴质感、纸片运动、触感音效
- 不适合：真人口播广告、精确可编辑图层、仅输出提示词

## 🎵 音乐与视觉创意

> 让画面跟随音乐节奏，让歌词成为视觉的一部分。

### 音乐 MV 动态字幕生成器
**一句话：** 基于音乐和歌词，生成节奏精准的 MV 分镜与动态字幕方案。

- 适合：风格化 MV、歌词驱动的音乐视觉、情绪短片
- 输入：音乐 + 歌词 + 参考图 / 角色 / 字体方向 / 情绪
- 输出：MV 概念、分镜提示词、歌词文字方案、拼接建议
- 特色：节拍拆解、空间字幕设计、长视频镜头拆解
- 不适合：普通字幕校对、照搬已有 IP、完全手工后期

[→ 查看完整技能文档](music-video-subtitle-generator/SKILL.cn.md)

## 🎮 创意实验与趣味玩法

> 跳出常规，探索独特的视觉风格与互动形式。

### 双人游戏开场视频生成器
**一句话：** 为双人合作游戏制作带角色和菜单交互动效的开场动画。

- 适合：游戏概念展示、角色化菜单、社交内容
- 输入：两位玩家名称 + 游戏名 + 视觉风格 + 可选角色参考图
- 输出：双人角色 + 玩家信息卡 + 菜单交互动效的开场视频
- 特色：先确认首图再生成视频，确保角色与 UI 风格统一
- 不适合：可玩游戏开发、复杂多页面 UI、无角色的通用片头

[→ 查看完整技能文档](co-op-game-intro-generator/SKILL.cn.md)

---

### 手绘实拍融合视频生成器
**一句话：** 让粗糙发光的手绘动画与实拍场景互动，产生超现实的 15 秒创意短片。

- 适合：单场景创意视频、视觉实验、趣味短片
- 输入：场景创意 + 接触对象 / 手部动作 + 情绪氛围
- 输出：15 秒 16:9 的 H3 可用视频提示词 + 生成建议
- 特色：手绘触碰变形、慢半拍手持追拍、非恐怖调性
- 不适合：精致 CG、恐怖跳吓、毛绒角色、多场景剪辑

[→ 查看完整技能文档](handdrawn-live-video-generator/SKILL.cn.md)

## 🔧 提示词与底层工具

> 想要更直接的控制？从这里开始。

### H3 提示词编写
**一句话：** 为 MiniMax H3 五种生成模式（T2VA / I2VA / FL2VA / L2VA / Ref2VA）编写结构化的视频生成提示词。

- 适合：已有明确画面构想、需要精确控制生成、其他技能的底层支撑
- 输入：多模态生成需求（文本 / 图片 / 视频 / 音频参考）
- 输出：符合 H3 格式的结构化提示词（integrated_multimodal_description + overall_soundscape + non_diegetic_music）
- 模式：
  - **T2VA** — 纯文本生成完整音视频
  - **I2VA** — 从首帧出发向前发展
  - **FL2VA** — 描述首尾帧之间的连续路径
  - **L2VA** — 推断开头并收敛到末帧
  - **Ref2VA** — 全参考模式，重写已有素材

[→ 查看完整技能文档（中文）](h3-prompt-writing/SKILL.cn.md) · [English](h3-prompt-writing/SKILL.md)
