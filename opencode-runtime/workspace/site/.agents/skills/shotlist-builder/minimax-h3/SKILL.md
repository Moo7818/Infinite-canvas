## 🎬 Animation & Storytelling

> Tell a complete story through animation.

### 3D Animation Short Generator
**One-liner:** From a story idea to a complete stylized 3D animated short with consistent characters and continuous scenes.

- Best for: Narrative animation, birthday keepsakes, brand stories, social shorts
- Input: Story concept / basic plot + duration / ratio / style confirmation

## 🔧 Prompts & Low-Level Tools

> Want direct control? Start here.

### H3 Prompt Writing
**One-liner:** Write structured MiniMax H3 video generation prompts for all five modes: T2VA, I2VA, FL2VA, L2VA, and Ref2VA.

- Best for: When you already have a clear visual vision, need precise control, or want to build on top of other skills
- Input: Multimodal generation requests (text / image / video / audio references)
- Output: Structured H3-format prompts (integrated_multimodal_description + overall_soundscape + non_diegetic_music)
- Modes:
  - **T2VA** — Build full audiovisual timeline from text
  - **I2VA** — Start from the first frame and develop forward
  - **FL2VA** — Describe the continuous path between first and last frames
  - **L2VA** — Infer a plausible opening and converge to the last frame
  - **Ref2VA** — Full-reference mode, rewrite existing assets
