# 安全检查（按改动触达面执行）

1. **密钥**：不硬编码 Key/Token。AI Key 存在浏览器本地并由前端请求服务，按真实数据流说明其暴露边界。
2. **不可信代码**：远端插件、自定义模型脚本和导入内容按不可信输入处理；变更加载/执行路径时重点审查权限、隔离、来源校验和错误处理。
3. **外部资源**：处理远端 URL/文件时校验协议、类型、大小和失败路径；避免无限等待、意外下载或自动执行。
4. **代理与网络**：代理只转发用户明确配置的目标；避免把密钥放入 URL、Referer、浏览历史或不必要的日志。
5. **存储**：按体量与敏感度选择 IndexedDB/localStorage；格式迁移或清理前说明影响并保留可恢复路径。
6. **日志**：错误和调试输出不得泄漏 `apiKey`、Token、敏感 URL 或用户内容；检查新增日志及异常序列化。
7. **本地 Agent**：核对监听地址、Token 生成与验证、CORS/Origin 和文件权限；认证信息不应出现在可分享链接或普通日志。
8. **资源边界**：变更超时、重试、轮询、并发或大小限制时记录适用环节与失败语义；可能产生费用、重复任务或明显资源消耗时先征求用户确认。

只执行与改动相关的检查项；接触外部输入、脚本执行、凭证、代理、文件写入或 Agent 权限时，必须在交付前说明审查结论和未覆盖部分。
