# 项目注意事项（上游 v0.18.0 实测）

* 改超时/重试/大小限制/并发上限等边界值前，先说明适用环节、默认值与失败处理并取得确认。
* 画布项目与“我的素材”在浏览器本地，不要误写已支持云同步。
* `API Key` 存浏览器本地，前端直连 OpenAI 兼容接口；安全说明写清楚。
* Docker 静态资源路径仍是待办，不承诺生产部署已完全验证。
* Agent 消息按 `threadId/turnId/itemId` 归属；实时事件只补未物化 turn，快照权威后不重复合并。
* Agent 协议版本与消息存储版本独立管理；存储升级先备份再迁移，未知版本/损坏/冲突时拒绝覆盖，不静默裁剪历史。
* 本地启动/验收不关用户已开的浏览器窗口；自动化验证用独立测试页。
* Grsai/AutoDL 双渠道配置见 `docs/assets/grsai-autodl-canvas-config.json`（导入整体替换，导入前先导出备份）。
