# 项目注意事项

- 边界值（超时/重试/大小/并发）变更前说明环节/默认值/失败处理并获确认。
- 画布+素材默认浏览器本地，未支持云同步。
- `API Key` 存本地，前端直连 OpenAI 兼容接口。
- Docker 静态资源路径待验证。
- Agent 消息按 `threadId/turnId/itemId` 归属，实时事件仅补未物化 turn，历史快照权威后不重复合并。
- 协议版与存储版独立管理，升级先备份，遇未知版/损坏/冲突拒绝覆盖，不静默裁剪。
- 本地验收不关闭用户窗口，用独立测试页。
- 版本/分支见 `docs/git-branch-strategy.md:1`。
